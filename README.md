# Hot, Heavy, Heavenly

*Neuer Song nach der Machart von "Dangerous, Delicious, Divine": gleicher Mix aus "Single Ladies" (Remady & Manu-L), "Crazy Sexy Marvellous" (Paffendorf), "Bumpy Ride" (Mohombi) und "Seratonin" (James Hype). Nur Feeling, Groove und Hook-Tricks, keine Originalzeilen oder Melodien.*

---

## 1. Was gleich bleibt wie bei Dangerous, Delicious, Divine

| Rezept von DDD | Hier |
|---|---|
| Geflüsterte Dreier-Hook mit Stotter | "H-h-hot, heavy, heavenly" (das gehauchte "H" klingt wie Atem) |
| Club-Ansage im Refrain | "All my night owls, get up on the floor!" |
| Strophen im Dancehall-Bounce, Pre-Chorus kippt auf geraden Kick | genau so |
| Männliche Toasting-Strophe | ja |
| Drop: rollender, verzerrter Bass + Silben-Chop | Chop "hea-hea-heavenly" |
| Trance-Pad im Breakdown, Gang-Vocals | ja |

**Neu:** Thema ist eine heiße Nacht, in der die Klimaanlage im Club ausfällt und alle trotzdem weitertanzen. Die Hook beginnt mit einem hörbaren Ausatmen ("hhh"), das im Drop als Percussion wiederkommt.

## 5. Produktions-Tipps

- **Wie bei DDD:** harter Wechsel Bounce → gerader Kick im Pre-Chorus.
- **Ausatmen als Sound:** Ein langes "hhh" aufnehmen, kurz schneiden und im Drop auf die Off-Beats legen, wie ein Hi-Hat.
- **Hook flüstern**, Stotter-Edit "h-h-".
- **Drop-Lead:** Silbe "hea-" aus "heavenly" schneiden und rhythmisch spielen.
- **Männerstimme** lässig, mit leichtem Dancehall-Akzent, keine Parodie.
